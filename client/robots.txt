# Every group below is INDEPENDENT: a crawler obeys only the group that names
# it, and ignores the "*" group entirely. So the Disallow rules have to be
# repeated in each group — a single Disallow in the "*" group would leave the
# host-side setup wizard and the host-control endpoints crawlable by every
# named bot here.
#
# The closed set, repeated in every group:
#   /go/         the click redirect. It counts a click and forwards to a
#                partner — there is nothing to index, and crawling it would
#                inflate the counter with traffic no person generated.
#   the baskets  /warenkorb, /kasse, /bestellung, /konto, /suche and their
#                English twins. Personal or transient, and none of them may be
#                cached either; src/middleware.ts is what actually enforces
#                that.
#   /install/    the host-side setup wizard.
#   /tds/        token-gated host control (/tds/cache/*, /tds/connect) — no
#                index value. Prefix-safe: it does not touch
#                /tds-runtime.json.
#
# Until 2026-10-02 this file had ONE group. Every AI agent therefore fell under
# "*" by accident rather than by decision, and the shop was absent from answer
# engines that read the named groups.
#
# AI search and answer engines are welcome — the content is meant to be found
# and cited. Per vendor there is a training crawler, a search index and an agent
# that fetches a page when someone asks about it. Blocking the search or the
# fetch agent takes the site out of that engine's answers (robotsTxt.test.ts).
#
# Dataset-only crawlers (CCBot, Bytespider, Amazonbot, Diffbot, YouBot, …) are
# deliberately NOT named. They feed no answer surface this site's readers use,
# every added group has to repeat the whole Disallow set, and the permissive
# "*" group already governs them.
